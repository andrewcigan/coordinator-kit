# Установка координатора — инструкция для Claude

Человек вставил фразу «Поставь координатора…» в новую сессию приложения Claude и этим попросил: скачать этот набор, поставить его в папку этой сессии, подключить хук значков в его `~/.claude/settings.json`, включить удалённый доступ (Remote Control) и сделать эту сессию координатором. Делай всё сам: человек не технарь, терминал не открывает. Говори с ним по-русски, коротко. Первой строкой предупреди: «Claude несколько раз попросит “Разрешить” — нажимайте».

## 0. Проверки (ничего не меняя)

- Главная папка = рабочая папка этой сессии (полный путь).
  - Это домашняя папка целиком или `/` — остановись: «Создайте папку AI в домашней папке и откройте новую сессию в ней».
  - В пути есть `/.claude/worktrees/` — сессия открылась в копии папки. Остановись: «Откройте новую сессию прямо в папке AI».
  - Папка внутри «Документов», «Рабочего стола» или iCloud Drive — предупреди (Mac будет спрашивать доступ, iCloud может выгрузить файлы), посоветуй `~/AI`; человек настаивает — продолжай.
- Система — `uname -s`:
  - `Darwin` — Mac, всё как написано;
  - `MINGW…` или `MSYS…` — Windows с Git Bash, всё как написано; главную папку можно передавать в виде `C:\Users\…\AI`;
  - команды идут в PowerShell, а `bash` не найден — это Windows без Git. Остановись и попроси человека поставить Git for Windows с https://git-scm.com (Download, всё по умолчанию), затем полностью закрыть и открыть Claude и отправить фразу снова: без Git Bash хуки на Windows не работают;
  - другое — ставим правила, скилл и группы, хуки не подключаем (скажи об этом).
- Одним запросом ToolSearch загрузи: `mcp__ccd_session__start_session`, `mcp__ccd_session_mgmt__detach_session`, `mcp__ccd_settings__get_settings`, `mcp__ccd_settings__set_setting`, `mcp__ccd_session_mgmt__set_remote_control`, `mcp__ccd_session_mgmt__set_session_title`, `mcp__ccd_sidebar__set_pinned`, `mcp__ccd_sidebar__list_groups`, `mcp__ccd_sidebar__create_group`, `mcp__ccd_sidebar__set_view`. Каких нет — запомни, шаги с ними пропусти и назови в отчёте (обычно помогает обновить приложение: Claude → Check for Updates). Нет `start_session` — чаще всего это значит, что сессию создали с телефона: такая сессия никогда не сможет запускать другие. Остановись и скажи: «Поставьте один раз за компьютером: новая сессия в приложении Claude на компьютере → папка AI → эта же фраза». Дальше координатором можно пользоваться и с телефона.

## 1. Скачать набор (если ещё не скачан)

Одной командой, во временную папку:

```bash
KIT=$(mktemp -d)/coordinator-kit && mkdir -p "$KIT" && curl -fsSL https://github.com/andrewcigan/coordinator-kit/archive/refs/tags/workshop-2026-10-22.tar.gz | tar -xz --strip-components=1 -C "$KIT" && echo "$KIT"
```

Команда печатает путь к набору — запомни его: переменные между командами не сохраняются, дальше подставляй этот путь вместо `<набор>`.

Не скачивается (нет сети, закрыт GitHub) — попроси у человека архив из чата занятия и спроси, где он лежит:
- это файл `.tar.gz` или `.zip` — `KIT=$(mktemp -d)/coordinator-kit && mkdir -p "$KIT" && tar -xf "<архив>" --strip-components=1 -C "$KIT" && echo "$KIT"`;
- это уже папка (Safari распаковывает сам) — набор и есть эта папка, если в ней лежит `install.sh`.

Не используй WebFetch для файлов набора: он пересказывает, а не копирует.

## 2. Поставить

```bash
bash "<набор>/install.sh" "<главная папка — полный путь>"
```

Покажи человеку итог установщика своими словами (2–3 строки). Код не 0 — прочитай вывод, исправь причину и запусти ещё раз: повтор безопасен.

## 3. Удалённый доступ

- `get_settings`: если `connect_new_sessions_to_remote_control` не `true` — `set_setting` с этим ключом и `true` (новые сессии сразу видны с телефона).
- `set_remote_control` с `session_id` = `"self"` и `enabled` = `true` (эта сессия видна с телефона).
- Отказ из-за того, что у сессии ещё не было ни одного законченного хода, — в отчёте попроси человека ответить «включи удалённый доступ» и на этот ответ включи. Другой отказ или ключа нет — пропусти и скажи.

## 4. Эта сессия становится координатором

- `set_session_title`: `"self"`, название `Координатор`.
- `set_pinned`: `"self"`, `true`.
- В группу себя не клади: закреплённая сессия при переносе открепляется.

## 5. Группы направлений

- `list_groups` (ошибка — повтори один раз).
- Для каждой строки таблицы в `<главная папка>/directions.md`: группа с точно таким именем есть — оставь; нет — `create_group` с этим именем и сразу `set_view` с `section_id` = id группы и `group_by` = `"none"`.
- Затем `set_view` без `section_id` с `group_by` = `"custom"`, чтобы группы были видны в боковой панели. Отказ — не страшно: в раскладке по разделам группы видны и так.
- Другие группы не трогай. Повтор установки не должен создавать дублей.

## 6. Включиться в роль

Прочитай сейчас `<главная папка>/CLAUDE.md` и `<главная папка>/.claude/skills/novoe/SKILL.md`: при старте этой сессии их ещё не было. С этого момента ты координатор и действуешь по разделу «Если ты сессия в самом корне…».

## 7. Отчёт человеку — 3–5 строк

- что поставлено и что пропущено;
- «Теперь один раз полностью закройте Claude и откройте снова (Mac — Cmd+Q; Windows — правый клик по значку Claude возле часов → Quit) — так в координаторе заработают сторож и напоминание про ❓»;
- после этого — проверочная фраза координатору: «Новый проект: Telegram-бот записи клиентов. Заведи его и запусти для него сессию»;
- название сессии руками не менять — каждое изменение значка начнёт спрашивать подтверждение.

## Убрать набор

- Из `~/.claude/settings.json` убрать запись `UserPromptSubmit` с `coordinator-status-icon.sh` (копия до установки — рядом, `settings.json.bak-coordinator-kit-…`), файл `~/.claude/hooks/coordinator-status-icon.sh` — в Корзину.
- Главная папка — обычная папка: проекты в ней остаются.
