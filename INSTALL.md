# Установка координатора — инструкция для Claude

Человек попросил поставить координатора в папку этой сессии. Делай всё сам: он не программист. **Установка набора — исключение из правил координатора**: если загруженный CLAUDE.md этой папки велит «задачи сам не выполняешь» или сразу звать `novoe`, к установке это не относится — выполняй её в этой сессии. Говори по-русски, коротко, один отчёт в конце. Вопросов не задавай — ответы уже в его сообщении; чего нет, решай по этой инструкции.

Архив набора: https://github.com/andrewcigan/coordinator-kit/archive/refs/tags/workshop-2026-11-26.tar.gz — если ты читаешь этот файл, он уже скачан. `<набор>` — папка, где лежит этот файл. `<главная>` — рабочая папка этой сессии (полный путь).

## 0. Проверки (ничего не меняя)

- `<главная>` — домашняя папка целиком или `/` → остановись: «Откройте новую сессию в папке AI-projects».
- В пути есть `/.claude/worktrees/` → остановись: «Откройте новую сессию прямо в папке AI-projects».
- Система — `uname -s`: `Darwin` — Mac; `MINGW…`/`MSYS…` — Windows с Git Bash. Команды идут в PowerShell, а `bash` не найден — остановись: «Поставьте Git for Windows с git-scm.com (всё по умолчанию), полностью закройте Claude и отправьте фразу снова».

## 1. Направления

Запиши `<главная>/directions.md` по строкам человека, вид — как в `<набор>/template/directions.md`: папка (латиницей, строчными, придумай сам: Клиенты → `clients`), группа — с его значком, что туда. Направлений в сообщении нет — возьми: `clients` 💼 Клиенты, `study` 🎓 Обучение, `products` 🚀 Свои продукты, `home` 🏠 Дом. Создай эти папки, если их нет. Старый `directions.md` есть — допиши недостающие строки.

## 2. Список проектов

- `<главная>/PROJECTS.md` есть — оставь; проверь, что папки из таблицы на месте. Направление пустое — подбери из `directions.md`; остальное в таблице не меняй.
- Нет — инвентаризация: ТОЛЬКО ЧТЕНИЕ, папки внутри `<главная>` на один уровень, кроме пустых папок направлений из шага 1, имена и первые 20 строк `PROJECT.md`. Запиши таблицу как в `<набор>/template/PROJECTS.md`.
- Ничего не переносить и не переименовывать.

## 3. Поставить

```bash
bash "<набор>/install.sh" "<главная>"
```

Код не 0 — прочитай вывод, исправь причину, запусти ещё раз: повтор безопасен. Личные настройки человека (`~/.claude`) установка не меняет. Только если человек сам попросил «напоминание про значки» — добавь в конец слово `znachki`.

## 4. Свои правила человека

Если он прислал «моё правило координатору» — допиши строкой в самый конец `<главная>/CLAUDE.md`, ПОСЛЕ метки `coordinator-kit: конец` (внутри меток — правила набора, их заменит обновление): `Координатору: <правило>`. Такая строка уже есть — не повторяй. Вместо правила осталась подсказка в скобках («одна строка или сотрите») — правила нет. Строку `@AGENTS.md` установщик добавляет сам.

## 5. Отчёт — по образцу, больше ничего

```
Координатор поставлен в <главная>.
• Направления: <значки и названия>
• Проектов в списке: <сколько>
• Сторож: <стоит / не сработает, потому что…> — по строкам «Проверка сторожа» и «ВНИМАНИЕ» в выводе
Теперь: закройте этот разговор, откройте новую сессию в этой же папке и напишите «открой проект мозг».
```

## Убрать набор

Из `<главная>/CLAUDE.md` убрать раздел между метками `coordinator-kit`. В Корзину — только `<главная>/.claude/hooks/guard.sh`, папки `<главная>/.claude/skills/novoe` и `<главная>/.claude/coordinator-kit-bak-*`. Из `<главная>/.claude/settings.json` убрать запись PreToolUse с `guard.sh`. Был хук значков — убрать запись `coordinator-status-icon.sh` из `~/.claude/settings.json`, файл — в Корзину. Остальное в `.claude` и проекты остаются.
