# Установка координатора — инструкция для Claude

Человек вставил фразу «Поставь координатора…» в новую сессию приложения Claude и этим попросил: скачать этот набор, поставить его в папку этой сессии, подключить хук значков в его `~/.claude/settings.json`, включить удалённый доступ (Remote Control) и сделать эту сессию координатором. Делай всё сам: человек не технарь, терминал не открывает. Говори с ним по-русски, коротко. Промежуточных отчётов не пиши — один отчёт в конце (шаг 7).

`<набор>` ниже — папка, где лежит этот INSTALL.md (рядом с ним `install.sh`). Если ты уже распаковал набор, чтобы прочитать этот файл, — шаг 1 пропусти.

## 0. Проверки (ничего не меняя)

- Главная папка = рабочая папка этой сессии (полный путь).
  - Это домашняя папка целиком или `/` — остановись: «Создайте папку AI в домашней папке и откройте новую сессию в ней».
  - В пути есть `/.claude/worktrees/` — сессия открылась в копии папки. Остановись: «Откройте новую сессию прямо в папке AI».
  - Папка внутри «Документов», «Рабочего стола» или iCloud Drive — предупреди (Mac будет спрашивать доступ, iCloud может выгрузить файлы), посоветуй `~/AI`; человек настаивает — продолжай.
- Система — `uname -s`:
  - `Darwin` — Mac, всё как написано;
  - `MINGW…` или `MSYS…` — Windows с Git Bash, всё как написано; главную папку можно передавать в виде `C:\Users\…\AI`;
  - команды идут в PowerShell, а `bash` не найден — это Windows без Git. Остановись и попроси человека поставить Git for Windows с https://git-scm.com (Download, всё по умолчанию), затем полностью закрыть и открыть Claude и отправить фразу снова: без Git Bash хуки на Windows не работают;
  - другое — ставим правила, скилл и группы, хуки не подключаем (скажи об этом в отчёте).
- ToolSearch, `max_results` = 10: `select:mcp__ccd_session__start_session,mcp__ccd_session_mgmt__detach_session,mcp__ccd_settings__get_settings,mcp__ccd_settings__set_setting,mcp__ccd_session_mgmt__set_remote_control,mcp__ccd_session_mgmt__set_session_title,mcp__ccd_sidebar__set_pinned,mcp__ccd_sidebar__list_groups,mcp__ccd_sidebar__create_group,mcp__ccd_sidebar__set_view`. `start_session` и `detach_session` здесь только проверяешь — при установке их не вызывай.
  - Нет `start_session` — чаще всего это значит, что сессию создали с телефона: такая сессия никогда не сможет запускать другие. Остановись и скажи: «Поставьте один раз за компьютером: новая сессия в приложении Claude на компьютере → папка AI → эта же фраза». Дальше координатором можно пользоваться и с телефона.
  - Нет других — шаги с ними пропусти и назови в отчёте (обычно помогает обновить приложение: Claude → Check for Updates).
- Шаг отказал из-за режима разрешений (авто-режим не пускает правку настроек) — попроси человека переключить режим под полем ввода на «Ask» и отправить «продолжай».

## 1. Скачать набор (если ещё не скачан)

Одной командой, во временную папку (WebFetch для файлов набора не используй: он пересказывает, а не копирует):

```bash
KIT=$(mktemp -d)/coordinator-kit && mkdir -p "$KIT" && curl -fsSL https://github.com/andrewcigan/coordinator-kit/archive/refs/tags/workshop-2026-10-22.tar.gz | tar -xz --strip-components=1 -C "$KIT" && echo "$KIT"
```

Команда печатает путь к набору — дальше подставляй его вместо `<набор>`: переменные между командами не сохраняются.

Не скачивается (нет сети, закрыт GitHub) — попроси у человека архив из чата занятия и спроси, где он лежит:
- файл `.tar.gz` — `KIT=$(mktemp -d)/coordinator-kit && mkdir -p "$KIT" && tar -xzf "<архив>" --strip-components=1 -C "$KIT" && echo "$KIT"`; на Windows путь к архиву сначала переведи: `"$(cygpath -u '<архив>')"`;
- уже папка (браузер распаковал сам) — набор и есть эта папка, если в ней лежит `install.sh`.

## 3. Удалённый доступ

- `get_settings`: если `connect_new_sessions_to_remote_control` не `true` — `set_setting` с этим ключом и `true`. Так все новые сессии на этом компьютере сразу видны с телефона.
- Для этой сессии `set_remote_control` сейчас не вызывай: в первом ходе сессии он всегда отказывает («Needs a session that has run a turn»). Его включит координатор на следующем сообщении человека (правило в CLAUDE.md главной папки).

## 4. Эта сессия становится координатором

- `set_session_title`: `"self"`, название `Координатор`. Значков себе не ставь — координатор их не носит.
- `set_pinned`: `"self"`, `true`.
- В группу себя не клади: закреплённая сессия при переносе открепляется.

## 5. Группы направлений

- `list_groups`. Ошибка — повтори один раз; снова ошибка — группы не создавай (иначе возможны дубли), в отчёте напиши: «группы появятся с первым проектом».
- Для каждой строки таблицы в `<главная папка>/directions.md`: группа с точно таким именем есть — оставь; нет — `create_group` с этим именем и сразу `set_view` с `section_id` = id группы и `group_by` = `"none"` (внутри группы не будет разбивки по датам).
- Другие группы не трогай. Повтор установки не должен создавать дублей.

## 6. Включиться в роль

Прочитай сейчас `<главная папка>/CLAUDE.md` и `<главная папка>/.claude/skills/novoe/SKILL.md`: при старте этой сессии их ещё не было. С этого момента ты координатор и действуешь по разделу «Если ты сессия в самом корне…».

## Убрать набор

- Из `~/.claude/settings.json` убрать запись `UserPromptSubmit` с `coordinator-status-icon.sh` (копия до установки — рядом, `settings.json.bak-coordinator-kit-…`), файл `~/.claude/hooks/coordinator-status-icon.sh` — в Корзину.
- Главная папка — обычная папка: проекты в ней остаются.
