# Координатор для Claude Code

Одна сессия-«Координатор» в главной папке принимает ваши задачи и сама их не делает: находит или заводит папку проекта с паспортом и запускает в ней отдельную сессию. Сессии раскладываются по группам направлений в боковой панели, а в названии каждой — значок статуса.

```
Вы: «Новый проект: Telegram-бот записи клиентов»
        │
   Координатор (закреплён, виден с телефона)
        ├─ ищет похожее среди проектов
        ├─ заводит agents/booking-bot/PROJECT.md и строку в PROJECTS.md
        ├─ запускает новую сессию в этой папке
        └─ кладёт её в группу 🤖 Мультиагентность и Telegram
                  │
            Новая сессия работает и ставит значок:
            ❓ ждёт вашего ответа · 🔴 важно · ✅ готово
```

Учебный набор воркшопа Pro Agents: четыре направления — по блокам дня. Потом перепишите под себя.

## Поставить

Нужно: Mac или Windows, приложение Claude (вкладка Code), подписка Claude. На Windows — ещё Git for Windows (https://git-scm.com): с ним Claude получает Git Bash, на котором работают хуки.

1. Создайте папку `AI` в своей домашней папке (можно прямо в окне выбора папки — кнопка «Новая папка»).
2. В приложении Claude откройте новую сессию в этой папке.
3. Вставьте и отправьте:

```
Поставь координатора: скачай архив https://github.com/andrewcigan/coordinator-kit/archive/refs/tags/workshop-2026-10-22.tar.gz, распакуй во временную папку и сделай всё по его INSTALL.md — включая хук значков в мой ~/.claude/settings.json и удалённый доступ. Главная папка — эта, а эта сессия станет координатором.
```

4. Нажимайте «Разрешить», когда Claude спрашивает (6–8 раз).
5. Один раз полностью закройте Claude и откройте снова (Mac — Cmd+Q; Windows — правый клик по значку Claude возле часов → Quit). Тогда в координаторе заработают сторож и напоминание про ❓.
6. Проверьте: напишите координатору «Новый проект: Telegram-бот записи клиентов. Заведи его и запусти для него сессию».

Название сессий руками не меняйте: значки ставит сам Claude.

## Что ставится

| Где | Что |
|---|---|
| `~/AI/CLAUDE.md` | правила для всех сессий в папке, правило значков, роль координатора |
| `~/AI/directions.md` | направления: папка → группа в боковой панели |
| `~/AI/PROJECTS.md` | список проектов (ведёт координатор) |
| `~/AI/infra`, `data`, `harness`, `agents` | папки направлений |
| `~/AI/.claude/skills/novoe` | скилл координатора «задача → папка → сессия» |
| `~/AI/.claude/hooks/guard.sh` | сторож: координатор не делает задачи сам |
| `~/.claude/hooks/coordinator-status-icon.sh` | хук: напоминает снять ❓, когда вы ответили |
| `~/.claude/settings.json` | одна запись, подключающая хук значков (копия до правки — рядом) |

## Переписать под себя

- Свои направления — в `directions.md`: папка латиницей, группа с эмодзи. Группы координатор создаст сам.
- Свои правила — в `CLAUDE.md`.
- Как координатор раскладывает задачи — в `.claude/skills/novoe/SKILL.md`.

## Если что-то не так

- **С телефона координатор не запускает сессии сам.** Так пока устроено приложение Claude: запуск — только по сообщению, набранному на компьютере. С телефона координатор заведёт папку и даст текст: на телефоне откройте новую сессию на своём компьютере в этой папке, вставьте текст и напишите координатору «готово» — он положит сессию в группу. Сам набор ставится один раз за компьютером.
- **Сессия появилась внутри координатора, а не отдельно.** Попросите координатора: «отвяжи её и положи в группу».
- **Значок ❓ не снимается.** Перезапустите приложение Claude: хук подхватывается при старте.
- **Координатор сам взялся за задачу.** Перезапустите приложение — сторож включится.
- **Пропал координатор.** Новая сессия в `~/AI` → «Ты координатор: назови себя Координатор, закрепи, включи удалённый доступ, проверь группы из directions.md».
- **Не очищайте координатора командой с компьютера.** Если разговор стал длинным — `/clear` с телефона.

Проверено на чистых Mac и Windows: тесты в GitHub Actions (вкладка Actions репозитория).

## Убрать

Попросите Claude: «убери набор координатора по разделу “Убрать набор” в INSTALL.md». Проекты в главной папке остаются.
