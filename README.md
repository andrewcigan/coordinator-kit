# Координатор для Claude Code

Одна сессия-«Координатор» в главной папке — дверь во все ваши проекты. Сама задачи не делает: находит проект, читает, на чём остановились, и открывает в нём сессию. Новое дело — заводит папку с журналами.

```
Вы: «открой проект мозг»
        │
   Координатор
        ├─ находит строку в PROJECTS.md
        ├─ читает PROJECT.md и верхнюю запись ХОД.md
        ├─ говорит в три строки: где лежит, на чём стоим, что дальше
        └─ открывает сессию в папке проекта — она продолжает
```

Учебный набор воркшопа Pro Agents. Живёт только на вашем компьютере.

## Поставить

Нужно: Mac или Windows, приложение Claude (вкладка Code). На Windows — ещё Git for Windows (https://git-scm.com).

Новая сессия в папке с вашими проектами, вставьте:

```
Поставь координатора в эту папку. Скачай https://github.com/andrewcigan/coordinator-kit/archive/refs/tags/workshop-2026-11-26.tar.gz, распакуй во временную папку и сделай всё по файлу INSTALL.md из архива.
```

Потом закройте разговор, откройте новую сессию в этой же папке и напишите «открой проект …».

## Что ставится

| Где | Что |
|---|---|
| `CLAUDE.md` | правила для всех сессий и роль координатора (ваш текст не трогаем, дописываем между метками) |
| `directions.md` | ваши направления и группы |
| `PROJECTS.md` | список проектов (если уже есть — ваш) |
| `.claude/skills/novoe` | как координатор открывает и заводит проекты |
| `.claude/hooks/guard.sh` | сторож: не даёт координатору делать работу самому |

Личные настройки в `~/.claude` набор не меняет.

## Если что-то не так

- **Делает задачу сам.** Закройте разговор, откройте новую сессию в этой же папке: сторож включается при старте.
- **Не открывает сессию.** Он даст одну строку: в какой папке открыть новую сессию и что написать.
- **Пропал координатор.** Новая сессия в главной папке — она и есть координатор.

## Убрать

Попросите Claude: «убери набор координатора по разделу “Убрать набор” в INSTALL.md». Проекты остаются.

## Для тех, кто дорабатывает набор

- Тесты: `bash tests/run.sh` (они же идут в GitHub Actions на чистых Mac и Windows).
- Тесты перед каждым коммитом: `git config core.hooksPath .githooks`.
- Правила для ревью — `CODING_STANDARDS.md`.
