# Направления

Каждая строка — направление: папка внутри главной папки и группа в боковой панели Claude, куда координатор кладёт сессии этого направления.

| Папка | Группа в боковой панели | Что туда |
|---|---|---|
| `infra` | 🖥️ Инфраструктура | серверы, деплой, VPN, домены, «жив ли сервер» |
| `data` | 🗄️ Базы данных | базы, Supabase, схемы данных, персональные данные |
| `harness` | 🧰 Разработка по harness | правильная разработка: правила, тесты, хуки, порядок работы |
| `agents` | 🤖 Мультиагентность и Telegram | команды агентов, Claude в Telegram, боты |

## Как переписать под себя

1. Поменяй строки таблицы: папка — латиницей, строчными; группа — с эмодзи в начале.
2. Создай папки новых направлений (или попроси координатора).
3. Группы этих четырёх направлений создаются при установке; группу нового направления координатор создаст сам при первом проекте в нём. Старую группу переименуй или удали в боковой панели сам.
